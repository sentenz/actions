# Doxygen Documentation Examples

This directory contains multiple focused examples demonstrating different aspects of Doxygen API documentation for C++.

## Examples

### 1. [Basic Example](./basic-example/)
**Focus**: Simple functions and basic documentation

Demonstrates:
- File and function documentation
- Parameter and return value documentation
- Exception documentation with `@throw`
- Inline code examples with `@code` blocks
- Warning notes with `@warning`

**Files**: `calculator.hpp`, `calculator.cpp`  
**Lines**: ~60 total

---

### 2. [Classes Example](./classes-example/)
**Focus**: Object-oriented code and class documentation

Demonstrates:
- Namespace documentation
- Struct documentation
- Class documentation with methods
- Member variable documentation
- Constructor documentation
- Getter method documentation

**Files**: `circle.hpp`, `circle.cpp`  
**Lines**: ~100 total

---

### 3. [Formulas Example](./formulas-example/)
**Focus**: Mathematical formulas with LaTeX notation

Demonstrates:
- Inline math formulas with `\f$ ... \f$`
- Display formulas with `\f[ ... \f]`
- Mathematical symbols (Greek letters, subscripts, superscripts)
- Summation notation
- Fractions and square roots
- Complex multi-line equations

**Files**: `statistics.hpp`, `statistics.cpp`  
**Lines**: ~140 total

---

### 4. [Inheritance Example](./inheritance-example/)
**Focus**: Class hierarchies and inheritance

Demonstrates:
- Abstract base classes
- Virtual and pure virtual functions
- Class inheritance documentation
- Cross-references with `@see`
- Method overriding
- Inheritance diagrams (generated by Doxygen)

**Files**: `shape.hpp`, `shape.cpp`  
**Lines**: ~160 total

## Using the Examples

### Generate Documentation for an Example

```bash
cd basic-example
doxygen -g
# Edit Doxyfile: set INPUT, EXTRACT_ALL, etc.
doxygen
```

### Using the Doxygen Action

```yaml
- name: Generate Documentation
  uses: sentenz/actions/doxygen@latest
  with:
    source-dir: tests/doxygen/basic-example/include
    output-dir: docs
    project-name: Basic Example
    extract-all: true
```

### Test All Examples

See `.github/workflows/doxygen-test.yml` for automated testing of these examples.

## Documentation Best Practices

Each example demonstrates specific best practices:

1. **Always document public APIs** - All public functions/methods should have documentation
2. **Use meaningful descriptions** - Explain what, why, and how
3. **Document parameters** - Describe each parameter's purpose and valid values
4. **Document return values** - Explain what is returned
5. **Document exceptions** - List all exceptions that can be thrown
6. **Provide examples** - Show how to use the API
7. **Use cross-references** - Link related functions and classes
8. **Format formulas properly** - Use LaTeX for mathematical expressions

## Learning Path

Recommended order for learning:

1. Start with **Basic Example** - Learn fundamental documentation syntax
2. Move to **Classes Example** - Understand OOP documentation
3. Study **Formulas Example** - Learn mathematical notation
4. Review **Inheritance Example** - Master class hierarchies
5. Reference **Comprehensive Example** - See everything together
